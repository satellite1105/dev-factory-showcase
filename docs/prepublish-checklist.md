## 自動チェックと検査の限界

公開用リポジトリのルートで実行します。公開版を更新した場合は、コミット後に --history を再実行してください。

```sh
python3 scripts/test_prepublish_check.py
python3 scripts/test_check_docs.py
python3 -m unittest discover -s examples/dummy-project/tests -t examples/dummy-project
python3 scripts/check_docs.py
python3 scripts/prepublish_check.py
python3 scripts/prepublish_check.py --history
```

`scripts/denylist.local.txt` は禁止語、`scripts/skill-names.local.txt` は外部 skill 名を一行に一語ずつ記すローカル専用リストです。空行と `#` で始まる行は除き、存在すれば自動で読み込みます。両方とも git 対象外のまま扱い、内容を公開物やログへ貼り付けません。見本の `scripts/denylist.example.txt` は実リストの代わりにはなりません。

権限のある手元資料との長文一致は、資料をコピーせずに指定します。複数資料は --reference を繰り返します。

```sh
python3 scripts/prepublish_check.py --reference "<手元の照合資料>"
```

`PASS` でも警告・検査省略を確認します。照合元なしでは長文一致を検査せず、空の名前リストによる検査も働きません。長文一致は50文字窓の完全一致で、言い換えは対象外です。外部 skill 名の本文検出はハイフンを含む名前だけで、それ以外はディレクトリ名のみです。内部名・モデル ID はローカル禁止語リストに登録した語だけが対象です。履歴検査は author・committer のメールとメッセージ本文を含みますが、正常な Co-Authored-By 行自体は違反としません。静的検査では GitHub 上の描画や、情報・権利の網羅的な安全性を保証できません。
