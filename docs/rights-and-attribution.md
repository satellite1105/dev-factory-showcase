# 権利と出典の方針

> 記述時点: 2026-10。内容は非公開の内部概要資料(v2 系)から概念レベルで書き下ろしたもので、内部仕様は今後変わる可能性があります。

## 公開向けの書き下ろし

このリポジトリの説明文は、開発の考え方を伝えるために新しく書いたものです。内部の手順書、役割の定義、設定、雛形の原文を配布するものではありません。内部実装の詳細や非公開情報は掲載しません。

事例の説明では、説明用に再構成した記録と、実際に実装・検証した部分を区別します。実績や検証済みという表現は、確認できる根拠の範囲で用います。

## 外部 skill の同梱・再配布をしない

外部 skill は同梱・再配布しません。由来や権利を確認できないものも外部由来として扱い、本文、定義、個別名を公開物へ持ち込みません。一般的な役割や進め方は、特定の外部 skill の文章を転用せずに説明します。

## 第三者の資料を含めない

第三者の非公開資料、実案件の記録、クライアントの情報、許諾のない文章や画像は収録しません。参照できる資料であっても、公開されているという理由だけで本文や図を転載しません。出所と公開可否が不明な素材は加えず、作者が確認します。

## 商標・製品名と独立性

Claude Code は Anthropic、Codex は OpenAI、GitHub は GitHub, Inc. の商標・製品です。それぞれの名称に関する権利は各権利者に帰属します。

本リポジトリは個人のプロジェクトであり、各社とは無関係です。各社による公式の提供、協賛、承認を示すものではありません。製品名は、説明に必要な対象を示すために用います。

## 参照はリンクのみ

外部資料を参照する場合はリンクで案内し、本文、図、画面のコピーを掲載しません。出典を示すことと、内容を再配布できることは別に確認します。非公開の根拠は「非公開の内部概要資料(v2 系)」などの概念的な表記にとどめ、内部のファイル名や所在を明かしません。

## 図は自作の Mermaid のみ

図はこの説明のために自作した Mermaid に限ります。第三者の図、ロゴ、画像やスクリーンショットは使いません。スクリーンショットからの個人情報や非公開情報の写り込みも避けます。Mermaid の静的検査と GitHub 上での描画の目視確認は別に行います。
