# 検証ステータス

> 記述時点: 2026-10。内容は非公開の内部概要資料(v2 系)から概念レベルで書き下ろしたもので、内部仕様は今後変わる可能性があります。

## 分類の定義

- **実機検証済み**: 実行した試験や実運用の記録で、その項目を確認できたもの。確認できた範囲は各行の根拠と限界に示します。
- **一部検証**: 仕組みの一部や特定の経路には実行記録があるものの、項目全体の確認には至っていないもの。
- **設計済み(未検証)**: 方針や手順はあるものの、検証結果を裏付ける記録を確認できていないもの。

根拠が見つからないものは設計済みに倒す方針です。基盤についての記録と、このリポジトリで実行した検査は別の表で示します。ある項目の成功を、別の項目の検証結果として扱いません。

## 「設計済み」に倒した方針

手順が書かれていることと、その手順を実行して確かめたことは区別します。運用が始まっていても、対象の動作を裏付ける記録がなければ `設計済み(未検証)` とします。確認できた経路が限られる場合は、その範囲と未確認の経路を併記して `一部検証` とします。

`実機検証済み` も、記載した環境・事例・時点での確認です。あらゆる案件への適用、完全な安全性、将来のバージョンでの同じ挙動を保証するものではありません。
